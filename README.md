# BoilerControl
Скетч для дистанионного контроля за работой котла отопления. Для быстрого выявления проблем в работе или отказов.
Реализован на ESP32. К контроллеру подключен выносной датчик температуры DS18B20, установленный на батарею отопления,
и датчик температуры и влажности SHT31, который установлен на корпусе, в котором находится контроллер, для контроля комнаты.
Датчики непрерывно измеряют температуру батареи и воздуха, при понижении температур ниже заданных уставок температуры
контроллер подает оповещения в телеграм-бот заданным адресатам.

На телефон админа устанавливается приложение GyverHub, позволяющее редактировать уставки температуры, остальные получают извещения и информацию о показаниях датчиков и значениях уставок через телеграм-бот.

С помощью GyverHub также задаются и изменяются имена и Телеграм ID пользователей телеграм бота, которым отсылаются уведомления о срабатывании уставок.
